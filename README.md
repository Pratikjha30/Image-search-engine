# 🖼️ Image Search Engine

A responsive Image Search Engine web application that allows users to search and explore high-quality images instantly. The application fetches images from an external API and displays them in a clean, user-friendly interface.

## 🌐 Live Demo

🔗 https://pratikjha30.github.io/Image-search-engine/

## 🚀 Features

- Search images using keywords
- Real-time image fetching from API
- Responsive design for all devices
- Load more images functionality
- Clean and modern UI
- Fast and interactive user experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- REST API
- Fetch API

## ⚙️ How It Works

1. User enters a keyword in the search box.
2. JavaScript sends a request to the image API.
3. API returns matching image data.
4. Images are dynamically displayed on the webpage.
5. Users can load additional images using the "Load More" button.
