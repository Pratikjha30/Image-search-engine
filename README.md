# 🔍 Image Search Engine

A responsive and modern **Image Search Engine** built using **HTML, CSS, and JavaScript** that fetches high-quality images dynamically from the **Unsplash API**.

Users can search for any image category and load more images instantly with a clean UI and smooth experience.

---

## 🚀 Features

- 🔍 Search images by keyword
- 🖼️ Fetch real-time images using Unsplash API
- 📄 "Show More" functionality for pagination
- 🎨 Responsive and attractive UI
- ⚡ Fast and lightweight project
- 📱 Mobile-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Unsplash API

## ⚙️ How It Works

1. User enters a keyword in the search box  
2. JavaScript sends a request to the Unsplash API  
3. Images are fetched dynamically  
4. Results are displayed in a responsive grid  
5. Clicking **Show More** loads additional images  

---

## 🔑 API Setup

This project uses the Unsplash API.

### Steps:

1. Create a free developer account on Unsplash  
2. Generate your API Access Key  
3. Replace this line in `script.js`:

```javascript
const key = "YOUR_ACCESS_KEY";
```

with your own API key.
